# LifeOS domain glossary

| Term | Meaning |
| --- | --- |
| Personal space | Private owner scope; never joinable as a team workspace |
| Organization | Shared work tenant with memberships and roles |
| Scope | `PERSONAL` + personal_space_id **or** `ORGANIZATION` + organization_id |
| Task | Canonical work item; boards/Today/Gantt are views |
| Time block | Planned calendar allocation; not a due date or time entry |
| Focus session | Personal execution timer; not attendance or billable proof |
| Time entry | Logged work effort against task/project |
| Attendance session | Presence/shift check-in; independent of focus/time entry |
| Billable unit | Commercial billing eligibility derived from approved sources |
| Personal journal (finance) | Balanced debit/credit posting set in the personal book |
| Business invoice | Commercial AR document with immutable issued snapshot |
| Correlation rule | Owner mapping from business event → personal income journal |
| Outbox event | Durable domain event row committed with the write |
